# Pramanik Bari (প্রামাণিক বাড়ি) — Digital Family Tree & Genealogy App

ডিজিটাল বংশলতিকা, পারিবারিক স্মৃতি অ্যালবাম এবং আত্মীয়তার সম্পর্ক অন্বেষণ অ্যাপ।

---

## 📱 ফিচারসমূহ (Features)

1. **ইন্টারেক্টিভ বংশলতিকা (Interactive Family Tree)**
   - জুম (Zoom-in/Zoom-out), প্যান এবং স্পর্শের মাধ্যমে সম্পূর্ণ বংশলতিকা ব্রাউজিং।
   - শাখা বিস্তারিত ও সংকুচিত করার অপশন (+ / - বাটন)।
   - পিতা-মাতা, স্বামী-স্ত্রী ও সন্তান-সন্ততিদের সুনির্দিষ্ট সংযোগ রেখা।

2. **পারিবারিক অনুষ্ঠান ও স্মৃতি অ্যালবাম (Family Events & Photo Albums)**
   - পিকনিক, ঈদ মিলনমেলা ও যেকোনো অনুষ্ঠানের নাম ও তারিখ অনুযায়ী অ্যালবাম তৈরি।
   - ক্যামেরা অথবা গ্যালারি থেকে একাধিক ছবি আপলোড।
   - গুগল ড্রাইভ থেকে সরাসরি উচ্চ রেজোলিউশনের ছবি লোড এবং এক ক্লিকে ফোনে ডাউনলোড (`Pictures/PramanikBari`)।

3. **স্মার্ট বয়স ও আত্মীয়তা গণনাকারী (Kinship & Age Calculator)**
   - জীবিত সদস্যদের বয়স এবং প্রয়াত সদস্যদের জীবনকাল স্বয়ংক্রিয়ভাবে বাংলায় প্রদর্শন।
   - যে কোনো দুই সদস্যের মধ্যে রক্ত ও পারিবারিক সম্পর্ক (যেমন: চাচা, মামা, ফুফু, খালা, চাচাতো ভাই/বোন) নির্ণয়।

4. **সবার জন্য উন্মুক্ত ও ক্লাউড সিঙ্ক (Google Apps Script / Drive Sync)**
   - কোনো আইডি-পাসওয়ার্ডের ঝামেলা নেই; পরিবারের যে কেউ সদস্য বা ইভেন্ট যোগ করতে পারবেন।
   - গুগল শিটস এবং গুগল ড্রাইভের সাথে সম্পূর্ণ স্বয়ংক্রিয় ডাটা সংরক্ষণ।

## 🚀 GitHub Actions দিয়ে APK বিল্ড এবং ডাউনলোড করার নিয়ম

এই রিপোজিটরিতে **GitHub Actions CI/CD** সক্রিয় করা আছে। আপনি ৩টি উপায়ে APK তৈরি ও ডাউনলোড করতে পারবেন:

### পদ্ধতি ১: সাধারণ Push বা Commit
- কোড পরিবর্তন করে `main` বা `master` ব্রাঞ্চে `git push` করলেই GitHub Actions স্বয়ংক্রিয়ভাবে APK বিল্ড করবে।

### পদ্ধতি ২: ম্যানুয়ালি Workflow রান করা (Manual Trigger)
1. GitHub রিপোজিটরির ওপরের মেনু থেকে **"Actions"** ট্যাবে যান।
2. বাম পাশের তালিকা থেকে **"Build Pramanik Bari Android APK"** সিলেক্ট করুন।
3. ডানপাশে **"Run workflow"** ড্রপডাউন বাটনে ক্লিক করুন।
4. ব্রাঞ্চ সিলেক্ট করে সবুজ **"Run workflow"** বাটনে চাপ দিন।
5. ৩-৪ মিনিটের মধ্যে বিল্ড সফল হলে সবুজ টিকচিহ্ন (Green Checkmark) দেখতে পাবেন।

### পদ্ধতি ৩: APK ডাউনলোড করার নিয়ম (Download APK)
1. **GitHub Releases থেকে সরাসরি ডাউনলোড (সবচেয়ে সহজ):**
   - রিপোজিটরির হোমপেজের ডানপাশে **"Releases"** অপশনে যান।
   - সেখানে সর্বশেষ রিলিজ থেকে সরাসরি **`PramanikBari.apk`** ফাইলে ক্লিক করে আপনার অ্যান্ড্রয়েড ফোনে ডাউনলোড করে নিন।
2. **GitHub Actions Artifacts থেকে ডাউনলোড:**
   - **"Actions"** ট্যাবে যান এবং সর্বশেষ রান হওয়া বিল্ডে ক্লিক করুন।
   - স্ক্রিনের নিচের দিকে **"Artifacts"** সেকশনে যান।
   - **`PramanikBari-APK`** জিপ ফাইলে ক্লিক করে ডাউনলোড করুন এবং এক্সট্র্যাক্ট করে APK টি ফোনে ইনস্টল করুন।

## 📲 ফোনে ইনস্টল করার নিয়ম (Installation Guide)

1. ফোন বা ব্রাউজার থেকে ডাউনলোড করা `PramanikBari.apk` ফাইলটিতে ট্যাপ করুন।
2. যদি নিরাপত্তা বার্তা আসে, সেটিংস থেকে **"Allow installation from Unknown Sources"** (অজানা উৎস থেকে ইনস্টল করার অনুমতি) চালু করে দিন।
3. **"Install"** বাটনে ট্যাপ করলেই অ্যাপটি চালু হয়ে যাবে।

## 🛠 প্রযুক্তি ও ফ্রেমওয়ার্ক (Tech Stack)

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material 3)
- **Architecture:** MVVM + Clean Architecture with Kotlin Coroutines & Flow
- **Network & Sync:** Retrofit 2 + OkHttp 3 + Google Apps Script
- **Image Loading & Downloader:** Coil Compose + Android DownloadManager
- **Build System:** Gradle (Kotlin DSL .kts) + GitHub Actions CI/CD (JDK 21)
